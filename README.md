# Factory-to-Customer Shipping Route Efficiency Analysis

## Project Overview

This project analyzes shipping route efficiency for Nassau Candy Distributor.

The objective is to evaluate shipment volumes, recorded shipping lead times, ship modes, geographic patterns, factory-to-customer routes, and potential geographic bottlenecks.

## Objectives

- Analyze shipping routes
- Calculate recorded shipping lead time
- Compare ship modes
- Analyze regional and state-level shipment patterns
- Identify factory-to-customer routes
- Analyze shipping delays
- Develop an interactive dashboard

## Tools Used

- MySQL

## Key KPIs

- Total Shipments
- Total Sales

- Gross Margin
- Recorded Lead Time
- Delay Percentage
- Route Volume

## Project Components

### SQL Analysis

MySQL is used for:

- Data analysis
- Route analysis

- Geographic analysis
- Factory analysis
- KPI calculations

### Dashboard

The Streamlit dashboard provides:

- Route efficiency overview
- Geographic analysis
- Ship mode comparison
- Route drill-down
- Filters and KPIs

## Data Quality Note

The source dataset contains date inconsistencies that result in unusually large calculated shipping lead times. Therefore, lead-time results are presented as recorded/calculated lead times and should not automatically be interpreted as actual delivery performance.
